# Legacy Epics (Archived)

These epic documents are from the pre-superpowers planning workflow.
For current planning, see `docs/superpowers/specs/` and `docs/superpowers/plans/`.
These files are retained for historical reference only.

**Epic status lines are historical and not authoritative.** Each epic's
`**Status**` header records what was believed at authoring time and is never
revalidated — an epic marked "In Progress" may be complete, abandoned, or
superseded. For current state, trust the code, `docs/superpowers/`, and
`docs/deployment/`; treat anything written here as history.

**Do not add new files to this directory.**
New feature planning belongs in `docs/superpowers/specs/`.
